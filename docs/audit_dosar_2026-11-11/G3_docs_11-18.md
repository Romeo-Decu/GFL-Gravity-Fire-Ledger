## Cross-file findings

- **The central scientific claim is still untested.** Docs 13 and 18 frame GFL around transferring the microgravity thin-PMMA spread relation to normal-gravity downward spread. The repo has no normal-gravity measurement and no downward test identity. The transfer engine runs only on published summaries, with gate states declared by hand ("not yet computed from measured data"). Every held-out test is microgravity to microgravity.
- **Analytics modules are mostly missing as platform code.** `src/` has only the engine (it evaluates declared gates), the ledger and a read-only MCP server. All measurement, regime and ranking logic is research scripts in `tools/`. CRAM-1 (no de Ris calculation exists anywhere), CRAM-3, regime gates computed from data and a standalone anomaly detector are not built. CRAM-2 is exploratory (thickness exponent, RES-038).
- **Code contradicts a recorded rule.** `tools/rank_comparable_runs.py` L57-58 labels any "film" as PMMA. B3 and B13, whose table cells do not name PMMA, are then scored `material: match`. This breaks ISS-011 and ISS-051 and the "do not complete by presumption" rule in docs 13, 14 and 16. The inference should become an `inferred` state, not a match.
- **The zero-trust charter (doc 11) is half built.** The signed hash-chained ledger and owner/pipeline key separation are real and tested. Missing: the configurable identity/team/role model, the admissibility → verification → validation state machine, quarantine and release states, triple verification of data records, and half of the 10 adversarial tests (no source, wrong unit, unknown experiment, promotion, use of an unvalidated value in analysis). `main` was never technically protected, and one merge skipped the required review (DEC-024).
- **The B3 path ended differently from what doc 13 expected.** B3 turned out to be a partial burn with a faint near-limit flame (ISS-025). The first automatic run's B3 value of 2.222 mm/s (`BASSII_100UM_SPREAD_RATES_v0.1.json`) is a QC-rejected artefact: it tracked 94 mm of light against 64 mm burnt. It sits close to NASA's 2.2 mm/s by coincidence and must never be cited. The acquisition package for B3 is still an empty template.
- **Uncertainty is not yet credible as a validated module.** Pooled interval coverage was 15/24 on synthetic truth. The reference front definition is biased when the edge sharpens (ISS-047). Edge-to-front offset drift is not covered (ISS-050). The sample-plane scale correction (ISS-020) and the flow at the sample (ISS-013; the fan calibration workbook is never used) are both open, so absolute rates and any flow-dependence claim carry unquantified systematics.
- **Doc 18's pilot acceptance criteria are only partly met.** No front detection was compared to manual annotations (synthetic ground truth was used instead, which is a defensible substitute but should be stated as such). Frame coverage gaps stay open (B3 253 in the table vs 43 NEF in PSI; B13 311 vs 188). The doc's "36 images" on the B3 proof sheet is not reconciled with the 43 NEF files.
- **The analysis/validation/quarantine split was implemented as pre-registered predictions, not as a declared split.** No quarantine list exists. The Release A cross-O₂ holdout (V target) is blocked by dim-flame tracking (ISS-029). Only 1 of 4 registered predictions was supported (RES-037). That is honest, but it is not evidence of transferability.
- **The reconciliation deliverables of doc 14 were replaced by the register.** No separate B3 or B1 reconciliation dossier and no claim-level register of earlier findings exist. Only B6 has a full characterisation sheet. A jury can trace B6 end to end, but no other run.
- **Some items are still open.** ISS-009 (130 vs 129 rows), ISS-001 (no UX specification), DEC-022 (clean-room one-command rebuild and breadth audit), the 2 vs 3 cm/s B3 flow discrepancy and the 100 µm Flame Analyzer threshold. The importer has no resume support.

Nothing in this report came from memory. Nothing new needs saving.
