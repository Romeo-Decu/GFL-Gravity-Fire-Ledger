## Cross-file findings

- **The physics layer has no code.** Docs 21, 22, 25.2 and 25.3 commit to Re, Pe, Sc, Le, Da, Ra, Fo, the time scales and the de Ris thin-fuel formula (CRAM-1, Release A target P). None of these is computed anywhere in `src/` or `tools/`. The only physics-flavoured calculations are the exploratory thickness exponent (`tools/thickness_exponent.py`) and the ratio predictions in `build_predictions.py`.
- **"Physics-based similarity" is not physics-based.** The transfer engine (0.1.3) evaluates gate states that are declared by hand from the source audit (DEC-043). The comparable-run ranking matches table cells. P3 in 25.2 (link the engine to physical evaluations) and ruleset v0.2 (regime gates computed from data) are not done, although Release A rates this module V.
- **Four of DEC-009's MVP analytics modules are missing.** CRAM-1, CRAM-3 and anomaly detection have specs only. CRAM-2 has exploratory evidence only (RES-038). Advanced transferability is partial: 4 ratio predictions, 1 supported, 1 not supported, 2 not testable. The cross-O₂ held-out test promised in docs 19 and 25.3 is blocked by ISS-029.
- **Some doc 21 modules were silently lost.** Dynamic dependency analysis (Pearson, Spearman, MI, TE), state estimation / EKF and the physical model and parameter registry have no spec, no code and no decision dropping them. This breaks doc 22's own rule that no original function disappears without a documented decision.
- **The flow-calibration chain is open, and it blocks the core analytics.** The fan calibration workbook was acquired but never parsed or inspected, and its external link was never resolved. The overlay was transcribed by hand at 3-s steps. ISS-013 (flow speed at the sample) remains open, so the velocity–flow curve, CRAM-2 regime classification and every Re/Pe-type number cannot be computed.
- **Scientific claims in docs 24, 25.0, 25.2 and 25.3 are contradicted by later repo results.**
  - B6 = 2.27 / 2.317 mm/s was superseded, first by 1.99 (DEC-041), then by 2.197 mm/s with interval 1.915–2.368 (RES-033).
  - B15 = 2.386 mm/s was never re-measured under any R-W rule and is absent from current results.
  - "B6 ≈ B15 despite higher flow, so thermal regime" (25.3 §7.10) was withdrawn by DEC-041(b).
  - B9, rejected by QC in 25.3 §7.7, is now measured and supports its prediction (RES-035).
  - The 25.3 wording "close to Carmignani ≈ 2 mm/s" must stay under DEC-029's ban on "validated" and "within uncertainty".
- **The measurement uncertainty is still incomplete.** The sample-plane scale correction (ISS-020) is open, and parallax and the luminous-edge-to-pyrolysis offset are UNKNOWN. ISS-050 shows the reported interval misses edge-drift bias. GFL's own blind test gave 3 of 4 coverage. NASA's §2.3.6 method was never re-run on the same images, as the red team asked.
- **Data and identity loose ends remain from docs 19 and 20.**
  - Open issues: 130 vs 129 rows (ISS-009), Fig. 5.8 digitization (ISS-014), PSI-62 (ISS-015), the 22-row MicroFire O₂ audit (ISS-012), the B19/B20 archive mapping (ISS-032), frame-count mismatches (ISS-024) and the B15/B17 mislabel (ISS-019).
